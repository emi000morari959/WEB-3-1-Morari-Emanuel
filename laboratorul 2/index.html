Partea 1 - Republica Moldova

Despre Republica Moldova

Republica Moldova este o țară situată în partea de est a Europei. Capitala țării este Chișinău. Moldova este cunoscută pentru vinăriile sale, locurile istorice și peisajele naturale.

Obiective turistice

  • Orheiul Vechi
  • Cetatea Soroca
  • Cricova
  • Mănăstirea Căpriana
  • Castel Mimi

Partea 2 - Norvegia

Despre Norvegia

Norvegia este o țară din nordul Europei, cunoscută pentru fiordurile sale, peisajele naturale și orașele sale moderne. Capitala Norvegiei este Oslo.

Activități pentru turiști

  1. Vizitarea fiordurilor norvegiene spectaculoase
  2. Explorarea obiectivelor din capitala Oslo
  3. Observarea aurorei boreale în nordul țării
  4. Drumeții montane în parcurile naționale
  5. Vizitarea muzeelor istorice și maritime

Partea 3 - Suedia

Despre Suedia

Suedia este o țară nordică din Europa. Capitala țării este Stockholm. Suedia este cunoscută pentru industria sa, design, tehnologie și cultură.

Termeni asociați Suediei

Stockholm
Capitala Suediei și unul dintre cele mai importante orașe ale țării.
IKEA
Companie suedeză cunoscută pentru mobilier și produse pentru casă.
Volvo
Marcă suedeză cunoscută în special pentru automobile și vehicule.
ABBA
Grup muzical suedez foarte cunoscut la nivel internațional.
